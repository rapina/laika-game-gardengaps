# 틈의 정원 / Garden of Gaps

장식된 갈대 마디를 좌우로 끌고 놓아 작은 딱정벌레가 지날 틈을 만드는 2–3분 퍼즐입니다. 이웃 갈대가 함께 움직이며, 세 번 막히면 갈대가 굳습니다. 8구간 뒤 젖은 잎에 닿으세요.

Drag and release decorated reed nodes to shape a passage for a small beetle. Neighbouring reeds follow; three blocks harden the reeds. Reach the wet leaf across eight sections in a 2–3 minute puzzle.

## Controls / 조작

- Pointer: drag a teal node sideways and release. / 청록 마디를 좌우로 드래그하고 놓습니다.
- Keyboard: Left/Right Arrow commits the central bundle; Enter/Space restarts; M mutes. / 좌우 화살표로 가운데 묶음을 확정하고 Enter/Space로 재시작, M으로 음소거합니다.
